# Production Deployment Security Checklist

## Deployment method

Use bootstrap scripts as the default production deployment path.

```powershell
./scripts/bootstrap-gcp.ps1 -ProjectId "<YOUR_PROJECT_ID>" -Region "us-west1"
```

```bash
PROJECT_ID=<YOUR_PROJECT_ID> REGION=us-west1 ./scripts/bootstrap-gcp.sh
```

## Required configuration

Frontend `.env.production` (generated by bootstrap):

```env
VITE_API_URL=https://<YOUR_API_SERVICE_URL>
VITE_API_BASE_URL=https://<YOUR_API_SERVICE_URL>
VITE_API_KEY=<GENERATED_PUBLIC_API_KEY>
VITE_FIREBASE_API_KEY=<FIREBASE_API_KEY>
VITE_FIREBASE_AUTH_DOMAIN=<YOUR_PROJECT_ID>.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=<YOUR_PROJECT_ID>
VITE_FIREBASE_STORAGE_BUCKET=<YOUR_PROJECT_ID>.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=<FIREBASE_SENDER_ID>
VITE_FIREBASE_APP_ID=<FIREBASE_APP_ID>
```

API runtime variables:

```env
GOOGLE_CLOUD_PROJECT=<YOUR_PROJECT_ID>
CORS_ORIGIN=https://<YOUR_FRONTEND_SERVICE_URL>
VALID_API_KEYS=<KEY_1>,<KEY_2>
BQ_DATASET=parliamentary_data
PARLIAMENT_ADAPTER=oireachtas
PARLIAMENT_NAME=Irish Parliament
PARLIAMENT_API_BASE_URL=https://api.oireachtas.ie/v1
PARLIAMENT_DATA_SOURCE=Houses of the Oireachtas Open Data API
```

## Security checks

- Verify HTTPS is active for frontend and API URLs.
- Verify CORS is restricted to the deployed frontend domain.
- Verify rate limiting is active on API endpoints.
- Verify Firebase authorized domains includes the deployed frontend host.
- Verify API key rotation process is documented and practiced.

## Runtime checks

```bash
gcloud run services list --region=us-west1 --project=<YOUR_PROJECT_ID>
gcloud run jobs list --region=us-west1 --project=<YOUR_PROJECT_ID>
gcloud scheduler jobs list --location=us-west1 --project=<YOUR_PROJECT_ID>
curl https://<YOUR_API_SERVICE_URL>/api/data-status
```

## Maintenance checks

- Rotate API keys on a regular schedule.
- Review Cloud Run and scheduler logs weekly.
- Re-run ingestion manually after major schema or adapter changes.
- Keep frontend and API dependencies up to date.
